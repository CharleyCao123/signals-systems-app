# 信号与系统互动学习工具

Signals and Systems Interactive Learning App

**在线使用**：<https://charleycao123.github.io/signals-systems-app/>

## 内容

- 十章知识点精讲（信号与系统概述、时域分析、傅里叶变换、拉普拉斯变换、z 变换、状态变量分析、变换对速查表）
- 12 个可交互动态图形实验（卷积动画、谐波合成、抽样混叠、s/z 平面极点联动等）
- 25 道分步解析例题、40 道章节自测题

## 本地使用

直接打开 `dist/信号系统学习工具.html`（单文件版，无需联网）。

## 目录

- `index.html` + `css/` + `js/`：开发版源码
- `dist/`：单文件构建产物（`node build-web.js` 生成）
